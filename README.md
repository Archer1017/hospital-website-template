# 医院网站基础模板

九页静态网站，包含首页、医院简介、科室、预约、就诊指南、医疗服务、健康资讯、联系与评价。

从历史开发代码恢复，身份、医生姓名、联系方式、地址和日期均已替换为匿名占位。内容用于展示页面布局，不代表真实医院、医疗服务或患者评价。

## 运行

运行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`；也可以直接打开 `index.html`。

## 范围

- 响应式导航、科室手风琴、资讯展开与预约演示表单。
- 表单仅在浏览器本地完成校验和提示，不发送或保存预约信息。
- 未接入挂号后台、地图服务或真实医疗数据。

## 验证

JavaScript 语法检查通过；本地页面、资源和导航链接检查通过。
